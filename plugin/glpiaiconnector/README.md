# GLPI AI Connector Plugin

Plugin administrativo para o GLPI AI Connector.

## Estado atual

- instalação/ativação validada em GLPI 10;
- configuração de operações e entidades;
- tabela de auditoria;
- compatibilidade de banco usando `$DB->query()`.

## Instalação

Copie a pasta `glpiaiconnector` para `<GLPI>/plugins/glpiaiconnector`, depois instale e ative em **Configurar → Plugins**.

O Gateway MCP continua sendo um serviço externo nesta versão.
